## workflow_map
### Item 1
- **stage**: Lead sourcing and intake
- **owner_roles**: ['Marketing/Lead Manager', 'ISA Lead', 'Team Leads']
- **current_process**: Leads originate from portals (Zillow Premier Agent live/tour/nurtured connections), Realtor.com feeds, IDX websites, PPC/social, referrals. Portal ‘connections’ are live-transferred or delivered to CRM; non-portal web leads arrive via forms/APIs.
- **common_tools**: ['Zillow Premier Agent (live phone/tour/nurtured connections)', 'Realtor.com integrations to CRM', 'Follow Up Boss (lead hub)', 'IDX website/landing pages (kvCORE/others, varies)']
- **manual_steps**: ['Configure sources and map fields/tags in CRM', 'Monitor duplicate or misrouted leads and manually reassign', 'Create/adapt action plans for new source types']
- **pain_points**: ['Live-call connections require immediate pickup; missed calls lower conversion', 'Different sources send different data (tags, MLS number), causing inconsistent routing', 'Separate systems (site forms, portals, spreadsheets) cause data gaps when not centralized']
- **why_painful**: CRMs must parse metadata (tags/MLS/zip) to distribute correctly; portal connections can be phone-first. When sources are not normalized, ops must manually fix routing and backfill fields.
- **business_impact**: Slower speed-to-lead and misrouted inquiries reduce agent acceptance/connection rates and ROI on paid lead sources. Centralization reduces export/import of PDFs and data gaps.
### Item 2
- **stage**: Lead routing and first response
- **owner_roles**: ['ISA/Lead Manager', 'Team Leads', 'Assigned Agent']
- **current_process**: CRM applies advanced rules (tags, price, zip, city/state, MLS number) to assign to an agent/group; default rules apply if conditions not met. Action plans (texts/emails/tasks) kick off.
- **common_tools**: ['Follow Up Boss Lead Flow (advanced rules, action plans)']
- **manual_steps**: ['Tune routing logic and exceptions (e.g., lender pairing, ponds)', 'Manual reassignment on agent availability or coverage gaps']
- **pain_points**: ['Edge cases (missing tags/MLS or unrecognized source formats) bypass rules', 'Manual escalation needed for specializations (luxury, geo-farm) not perfectly tagged']
- **why_painful**: Rules are processed top-to-bottom; if source data is inconsistent, human intervention fixes defaulted or misrouted leads.
- **business_impact**: Queue delays and rework lower contact rates; missed SLA on live connections can forfeit the My Agent relationship with buyers.
### Item 3
- **stage**: Listing appointment prep (CMA and presentation)
- **owner_roles**: ['Listing Agent', 'Listing Coordinator']
- **current_process**: Agent prepares CMA and listing presentation using MLS data and brokerage-branded templates; optional automated CMAs to nurture prospects.
- **common_tools**: ['Cloud CMA (MLS-fed CMA, branded presentations, admin tools for brokerage consistency)']
- **manual_steps**: ['Review comps for outliers; customize narrative and adjustments', 'Assemble property-specific materials (floor plans, upgrades)']
- **pain_points**: ['MLS data needs curation; not all comps are relevant without manual review', 'Ensuring brand consistency across agents without admin tooling']
- **why_painful**: Automated CMAs still require human judgment to avoid mispricing from non-comparable sales.
- **business_impact**: Poorly curated CMA risks over/underpricing, longer DOM, and lower net proceeds; admin tools reduce brand inconsistency and prep time.

### Item 7
